# jarvis-updates

Kanał aktualizacji aplikacji **Jarvis** (desktop).

Ten repozytorium **nie zawiera** kodu źródłowego aplikacji.

- `manifest.json` na gałęzi `main` — informacja o najnowszej wersji (numer, URL paczki, SHA-256, opis).
- Paczki `.zip` są dołączane do **GitHub Releases** (Assets).

Aplikacja Jarvis sprawdza:

`https://raw.githubusercontent.com/filiph466-ui/jarvis-updates/main/manifest.json`
